# SwitchCore iOS

Emulatore sperimentale di Nintendo Switch per iPhone, con interprete ARM64 e presentazione Metal. La prima milestone riguarda homebrew NRO liberamente distribuibili. Il dispositivo di riferimento è iPhone 14 Pro.

Licenza GPLv3. La provenienza del motore e le scelte tecniche sono documentate in [Analisi delle basi disponibili](docs/ricerca.md).
